# Unified feature PR

## English

Brings the app-settings redesign, route selector follow-up, theme P1 presets, model catalog
diagnostics, and the four host write-entry points together on top of the latest upstream tree.

- Settings: searchable 19-item categorized settings home aligned with the web menu.
- Model picker: catalog diagnostics (raw / parsed / owner / allowed), unique row keys, natural list rendering.
- Route selector: follow-up failure feedback with i18n and tests.
- Theme: four presets (classic blue, mist purple, forest green, warm amber) with validated accent fallbacks.
- Four write-entry points remain reachable from the settings home.

## 中文

在最新上游代码基础上合入应用设置重做、路由选择器后续、主题 P1 预设、模型目录诊断与四个主机写入口。

- 设置：与 Web 菜单对齐的、可搜索的 19 项分类设置主页。
- 模型选择器：目录诊断（raw / parsed / owner / allowed）、唯一行键与自然列表渲染。
- 路由选择器：后续失败提示，含国际化与测试。
- 主题：四套预设（经典蓝、雾紫、森林绿、暖琥珀），带合法性校验的强调色回退。
- 四个写入口均可从设置主页进入。
